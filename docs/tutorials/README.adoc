== Reading and rendering

Read `.adoc` directly or use an AsciiDoc editor preview. With Asciidoctor CLI
available, run from the repository root:

[source,powershell]
----
asciidoctor -D "$env:TEMP/worker-coordinator-tutorials" docs/tutorials/*.adoc
----

This produces HTML in a temporary folder. Use the repository source or editor
preview for relative source-file links; these expect the checked-out directory
layout, including the sibling `url-shortener-lab` for companion links. Keep
rendered pages together so cross-tutorial HTML navigation resolves.

An Asciidoctor PDF converter can additionally produce PDF; it is a separate
toolchain. No rendering dependency is added to the application Maven build.
